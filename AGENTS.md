# Agent instructions for this repository

Whichever AI tool or model you are — Claude, GPT/Codex, Gemini, Copilot, Llama,
or anything else — read [AI-HANDOFF.md](AI-HANDOFF.md) before doing anything
else in this repository. It is the single, tool-agnostic source for:

- who the founder is and how he wants to be worked with;
- the standing instruction to challenge him directly when something is wrong,
  not just comply;
- how this repository (`kit/` vs `docs/`) actually works;
- current state, honestly, as of its own last-updated date.

Do not duplicate that content here or anywhere else — if it drifts out of
date, fix it in `AI-HANDOFF.md`, the one place it lives.
