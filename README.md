# Project OS

Project OS is a personal product-development operating system — a set of practices, structures, and tools built from evidence gathered across previous software projects.

It is not designed speculatively. It is assembled retroactively, from what actually happened.

The core rule:

> We do not add something to Project OS because we can imagine needing it. We add it because previous work demonstrates why it should exist.

This repository is currently in a **discovery and archaeology phase**. Before anything is built, prior projects are examined to surface the patterns, decisions, and failures that justify each future addition.
