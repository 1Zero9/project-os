# Project OS — Action Log

This is the Project OS-level companion to project-specific action logs. Record
only actions that change Project OS direction, operating method, evidence
classification or cross-project continuity. Product actions belong in their
own experiment log.

Each entry records: **action → result → evidence → learning → iteration
decision → next action**.
