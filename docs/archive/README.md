# Archive

Experience, not instructions.

These 42 documents record how Project OS was developed between 14–17 September
2026: ten experiments, four strategic checkpoints, seven project archaeologies,
the evidence logs behind them, and the superseded v0.2 candidate gates.

They are kept because the findings are real and occasionally worth citing. They
are archived because producing them had become the work — 16,000 lines of
analysis and no asset a future project could use.

Nothing here governs current behaviour. Do not treat a document in this
directory as an instruction, a control, or authority for a decision. Read one
only when a specific live question sends you to it.

What remains live: `PRINCIPLES.md`, the
[Delivery Brief and Proof-and-Stop Gate](../candidates/V02-DELIVERY-BRIEF-AND-PROOF-GATE.md),
the [learning register](../strategy/LEARNING-REGISTER.md), and `kit/` — the
only part that a new project actually consumes.

The most useful single page here is
[Lucy's archaeology](archaeology/001-lucy.md), which names the process event
horizon this archive exists to escape.
