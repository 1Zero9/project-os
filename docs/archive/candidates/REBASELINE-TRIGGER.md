# Rebaseline Trigger and Recovery — v0.2 Candidate

**Stop trigger:** invoke immediately when the founder says the result does not
match the brief; two correction cycles occur without acceptance; detail work
continues while CORE elements are missing; technical validation passes but
founder-visible acceptance fails; a temporary experiment is treated as
permanent; an authoritative requirement is silently omitted/simplified; budget
is exceeded without accepted value; or inherited implementation is being
optimised rather than approved intent.

## Recovery procedure

1. **Stop implementation.** Do not make another corrective feature/styling pass.
2. **Preserve evidence.** Record revision, screenshots, technical results,
   feedback, budget/cycle figures and any temporary-state dependency.
3. **Find the last useful checkpoint.** Name the last source/revision the
   founder accepted or that faithfully represented approved direction.
4. **Re-read authoritative sources.** Reconfirm authority; do not derive it
   from code or repeated assistant notes.
5. **Assess each requirement.** Mark PRESENT/PARTIAL/MISSING and link evidence.
6. **Separate structural gaps from styling defects.** Structure includes
   information architecture, geometry, hierarchy and required behaviour;
   styling is surface treatment after structure is proven.
7. **Make the smallest founder-visible structural proof.** It must demonstrate
   the missing structure from committed, reproducible state before detailed work.
8. **Obtain founder approval.** Record acceptance, deferrals, replacements,
   revised budget and boundary in the baseline.
9. **Resume only inside that boundary.** Re-run the Fidelity Gate after the
   proof and each material correction.

## Retention decision

Do not automatically discard working code. During step 5, classify existing
logic, data handling, accessibility work and tests as retain / adapt / remove
based on whether they support the reconfirmed requirement register. Preserve
only items that do not constrain or contradict the approved intent.
